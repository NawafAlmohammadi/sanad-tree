# شجرة الأسانيد

الموقع كامل للتشغيل على جهازك: مكتبة عربية من ١٠ روايات (٤ صحيحة، ٣ ضعيفة، ٣ موضوعة)، خريطة متحركة للأسانيد، بطاقات للرواة ومصادرهم، بطاقة المتن في نهاية المسار، وضع داكن، ومساعد يجيب فقط من بيانات المشروع. تبدأ الصفحة بانتظار اختيار المستخدم.

هذه نسخة مستقلة تعمل بخادم Node.js على جهازك. لا تحتاج حساب ChatGPT أو Codex أو Cloudflare، ولا مفتاح الفريق. القالب والإعدادات الخاصة بالموقع المستضاف استُبدلت بإعداد تشغيل محلي. النصوص والأسانيد والرواة ومنطق الحماية والواجهة نفسها محفوظة.

## التشغيل على Windows

1. ثبّت [Node.js](https://nodejs.org/en/download)، إصدار٢٢٫١٣ أو أحدث؛ اختر إصدار LTS. تأتي معه npm.
2. فك ضغط ZIP بالكامل. افتح مجلد `sanad-tree` الذي فيه هذا الملف و`package.json`، ولا تشغّل من داخل الملف المضغوط.
3. اضغط مرتين على `SETUP.cmd` مرة واحدة. يحمّل المكتبات من الإنترنت وينشئ ملف `API.env` فارغ المفاتيح. انتظر ظهور Setup complete.
4. للمساعد الخارجي، افتح `API.env` بالمفكرة وضع مفتاحك بعد `AI_KEY_GEMINI=` ثم احفظ. هذا اختياري؛ الموقع والمساعد المباشر يعملان دون مفتاح.
5. اضغط مرتين على `START.cmd`. افتح **http://127.0.0.1:5173** بعد بدء الخادم. اترك نافذة التشغيل مفتوحة، وأوقفه بـ Ctrl+C.

تأكد أن اسم الملف `API.env` وليس `API.env.txt`. لا يلزم إنشاء قاعدة بيانات أو دفع رسوم استضافة للتجربة المحلية. يلزم الإنترنت للتثبيت، وللمساعد الخارجي وفتح المراجع وتحميل الخطوط؛ يعرض المتصفح خطاً بديلاً عند تعذر الخط.

## التشغيل من الطرفية على Windows / macOS / Linux

افتح الطرفية داخل مجلد المشروع، ثم:

```sh
node scripts/setup.mjs
npm ci
npm run dev
```

ملف القفل `package-lock.json` يثبت نسخ المكتبات للتثبيت المتكرر. `node_modules` لا يدخل ZIP أو GitHub؛ ينزله كل جهاز عبر npm ci. لتغيير المنفذ: `npm run dev -- --port 5174`.

## ملف الـAPI

`API.env.example` نموذج آمن مرفق، و`API.env` ملف إعداد خاص بصاحب الجهاز. بعد أي تعديل أوقف الخادم وشغّله مجددًا.

```dotenv
AI_KEY_GEMINI=ضع_مفتاحك_هنا
AI_KEY_GROQ=
AI_MODELS=
AI_KEY_PRIMARY=
```

أنشئ مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/apikey). المجانية والتوفر وحدود الاستخدام تتبع حسابك وموديلك عند المزود؛ هذه الحزمة لا تفعّل فوترة أو ترقية. لا تضع المفاتيح في ملفات الواجهة أو داخل config/ai-models.json. لا ترفع `API.env` أو `.env` على GitHub. الملفات النموذجية فقط قابلة للرفع، و.gitignore يستثني الأسرار.

تقرأ هذه النسخة `API.env` أولًا؛ إذا لم يوجد تقرأ `.env`. متغيرات الخادم الموجودة مسبقًا لها الأولوية. لا يحتاج التشغيل إلى الملفين معًا. ملفات الإعداد الخاصة غير متاحة عبر خادم التطوير.

الموديلات الافتراضية في [config/ai-models.json](config/ai-models.json): Gemini وGroq. يمكن تغيير معرف الموديل أو إضافة مزود متوافق أو Anthropic. أسماء المفاتيح تبقى متغيرات خادم باسم AI_KEY_*. `AI_MODELS=[]` يعطل الموديلات الخارجية صراحة. [إعداد المساعد](docs/API-SETUP.md).

## كيف تتأكد أنه يعمل؟

اختر حديثًا، شاهد المسار من مصنف الكتاب إلى النبي ﷺ، واضغط راوياً لعرض معلوماته ومصادره. بدل الوضع الداكن وافتح «المتن والمصدر» لمراجعة نص الإسناد. بدون مفتاح اختر «الإجابة من المصادر». مع مفتاح اختر Gemini وجرب «اشرح لي هذا السند». جرب «اكتب لي كود بايثون»: يجب أن يمتنع.

وجود المفتاح يجعل الموديل قابلاً للاختيار، لكنه لا يثبت قبول المزود للمفتاح أو توفر الحصة؛ الاختبار الفعلي هو إرسال سؤال. عند انشغال الخدمة 503 يعرض الحقائق من المصادر مع إشعار واضح دون نسبة الإجابة للنموذج. الأخطاء الأخرى تعرض تعذر الاتصال. في الروايات الموضوعة يعرض تنبيه عدم ثبوت النسبة قبل النص وفي إجابات المساعد.

## الاختبارات والبناء

```sh
npm test
npm run check:data
npm run check:types
npm run build
npm run start
```

`start` يشغل نسخة Node المبنية على نفس العنوان١٢٧٫٠٫٠٫١:٥١٧٣. أوقف dev قبل start لأنهما يستخدمان المنفذ نفسه. ملفات dist ناتج بناء، وليست بديلاً عن الشيفرة في GitHub. لا يمكن تشغيل المساعد من ملف HTML مفتوح مباشرة أو من GitHub Pages؛ يلزمه الخادم المشمول هنا.

نجح التثبيت الجديد، و53 اختبارًا، وفحص البيانات والأنواع، والبناء وتشغيل الإنتاج. [نتائج تحقق الحزمة](docs/PORTABLE-VERIFICATION.md).

| الملف / المجلد | وظيفته |
|---|---|
| app/ | الواجهة العربية ومسارات API على الخادم |

| lib/grounding.mjs | تحديد الأسئلة المسموحة واسترجاع الأدلة والتحقق منها |

| SETUP.cmd / START.cmd | تجهيز وتشغيل Windows |

| tests/ | اختبارات فصل الهويات والمصادر ومنع الخروج عن المجال |

كل مسار ونص وحقل موثق مرتبط بمرجعه. حكم الحديث مستقل عن لون الراوي؛ الصحابي والنبي ﷺ أخضر بصفتهما، والمعلومة الغائبة لا تكمل بالتخمين. في البخاري١٠ فرعان منفصلان. عمر بن سنان وعلي بن إسحاق كما في نص الطريق؛ لا حكم مستقل مدخل لهما، وتظهر بطاقتهما رمادية.

مراجع الأحاديث العشرة و٥١ هوية و٦٢ مصدرًا في [ملف المراجعة الكامل](docs/TEN-HADITHS-REVIEW.md). [طريقة إدخال البيانات](docs/DATA-INPUT.md) و[البنية](docs/ARCHITECTURE.md). لا تبحث النسخة تلقائياً في الإنترنت؛ أضف بيانات راجعتها أنت مع مصدر كل حقل. اختبارات البرنامج لا تثبت صحة المادة العلمية؛ راجع النصوص والطبعات والأحكام بنفسك.

## مشاكل شائعة

- npm غير معروف: أعد فتح الطرفية بعد تثبيت Node.js وتأكد من node --version وnpm --version.
- PowerShell يمنع npm.ps1: استخدم `npm.cmd ci` و`npm.cmd run dev` أو نافذة Command Prompt. لا يلزم تغيير سياسة أمان الجهاز.
- المنفذ مستخدم: أغلق نافذة تشغيل المشروع السابقة، أو شغله بمنفذ آخر كما سبق.
- المساعد الخارجي غير مفعل: تأكد من API.env واسم المفتاح، ثم أعد تشغيل الخادم.
- نفاد حصة / خدمة غير متاحة: راجع حساب المزود، أو اختر الإجابة من المصادر.
- تاريخ راوٍ غير مسجل / طلب عام: الامتناع مقصود؛ أضف مصدرًا قبل إتاحة المعلومة.

## الحقوق

حقوق شيفرة المشروع للفريق؛ لم نختر ترخيص إعادة توزيع بالنيابة عنه. المكتبات تحت تراخيصها المذكورة في [NOTICE.md](NOTICE.md). مراجع البيانات لها حقوق مستقلة؛ نشر الشيفرة لا يمنح حقوق إعادة نشر المواقع والمصادر. لا تتضمن الحزمة مفتاح API أو بيانات حساب خاصة.
