# تفعيل Groq من حساب الفريق

تم التحقق من وثائق Groq في 1 أكتوبر 2026: توجد خطة مجانية بحدود. اخترنا `openai/gpt-oss-20b` لأنه مدرج في حدود الخطة المجانية ويدعم JSON Schema الصارم. لا نعتمد Llama القديم الذي أصبح ظاهرًا كنموذج Enterprise في القائمة الحالية.

1. سجل دخولك إلى [Groq Console](https://console.groq.com/keys) وأنشئ مفتاح API في حساب الفريق على الخطة المجانية. لا يلزم التطبيق ترقية الخطة؛ لا نُفعّل أي ترقية تلقائية.
2. للاختبار المحلي، ضع المفتاح في `.env` بعد `AI_KEY_GROQ=`. الملف مستثنى من Git والأرشيف. لا ترسل المفتاح في المحادثة.
3. للنشر، أضف `AI_KEY_GROQ` كسر في إعدادات بيئة الموقع، ثم أعد النشر. ملف `.env` لا يرسل إلى منصة النشر. يمكن للمساعد نقل المفتاح من الملف المحلي إلى إعدادات الموقع عند طلبك، دون طباعة قيمته.
4. افتح قائمة «طريقة الإجابة» واختر Groq. عدم وجود المفتاح يجعل الخيار غير مفعل. لا تُعرض رسالة نجاح اتصال قبل تجربة طلب فعلي.
5. جرّب شرح السند ثم طلب برمجة، وتأكد من ظهور المصادر في الأول والامتناع في الثاني. راجع الاستهلاك في حساب Groq.

الإعداد العام في `config/ai-models.json` بلا أسرار؛ يمكن تبديل المزود/الموديل هناك أو بقائمة `AI_MODELS` على الخادم. تظل الحماية نفسها. لكل طلب يرسل السؤال والأدلة المحددة فقط، دون بقية المكتبة أو سجل المحادثة أو بحث إنترنت. يطلب الخادم قرارًا ومعرفات أدلة، لا مقالًا حرًا، ثم يعرض المعلومات المسجلة مع المصادر. JSON Schema يقيد المعرفات، والتحقق بعد الاستجابة يرفض أي معلومة غير مسجلة. معرفة الموديل السابقة لا تُمحى، لكنها لا تستخدم بوصفها مصدرًا للإجابة.

عند نفاد الحصة يظهر تعذر واضح مع إمكانية اختيار الإجابة المحلية؛ لا إعادة محاولات آلية ولا تبديل لموديل مدفوع. المجانية مرتبطة بخطة حساب المزود وحدوده، وليست ضمانًا لاستخدام غير محدود أو أسعار ثابتة. لا تحفظ مفاتيح داخل إعدادات الواجهة أو المستودع.

المراجع الرسمية: [الخطة وحدودها](https://console.groq.com/docs/rate-limits)، [النماذج](https://console.groq.com/docs/models)، [توافق API](https://console.groq.com/docs/openai)، [JSON Schema](https://console.groq.com/docs/structured-outputs). الاتصال الحقيقي ينتظر مفتاح الفريق، أما المحول والتحقق فمختبران بردود محاكاة.
