# Scientific-reference release — 6 October 2026

[Live demo](https://sanad-tree.nawaf-alsaadi.chatgpt.site/) · [Repository](https://github.com/NawafAlmohammadi/sanad-tree)

The release preserves the same ten reports and 22 route node orders while replacing the active source registry with the competition guide's approved references. Report texts and narrator entries use named Shamela editions, grades cite Dorar/edition text, and four English quotations use HadeethEnc with Arabic-version notes. Six reports retain Arabic where a reviewed replacement translation was not verified.

The unified assistant can search and retrieve approved original passages through Islamic Content MCP. Publisher grades and attribution are preserved, citations accompany generated paragraphs, and an independent evidence check gates display. Privacy preflight and personal/disputed-case referrals apply before downstream requests. Original source wording remains inspectable beside preserved versions.

The existing navy university design, merged maps, one-path tracing, narrator/compiler/wording side panels, fullscreen library, connected dragging and annotations remain available.

At least one valid external model API key is REQUIRED for AI-generated features. Keys are not included in GitHub or the downloadable project. The source APIs do not receive model keys. Dorar's live endpoint was blocked during verification and fails closed. See [API setup](API-SOURCES.md).

Automated data, type, source-policy and regression checks support this release; their outcome is recorded with the submission. **Human scientific and linguistic review required by page 8 remains pending.** See the [page-by-page compliance record](SCIENTIFIC-REFERENCE-COMPLIANCE.md). Model checking and passing tests do not constitute competition approval.
