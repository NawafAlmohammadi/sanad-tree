# Submission release — 6 October 2026

[Live demo](https://sanad-tree.nawaf-alsaadi.chatgpt.site/) · [GitHub](https://github.com/Nawafhikari/sanad-tree)

The local package matches the published demo's interface, recorded data, assets, model configuration, source validation and map behaviour. Its three API routes read local environment variables instead of the hosting platform's environment binding; this keeps the package runnable on Windows, macOS and Linux.

## Included

- Unified chain maps with recorded alternative paths and identity-safe shared narrators.
- Fullscreen map editing, connected narrator dragging, drawing, erasing and movable text.
- An embedded hadith library and nonmodal left panels for narrator details, compiler biographies and source-linked transmission wordings.
- Path-by-path tracing: earlier paths turn off, previous narrators in the current path glow softly and the active narrator has stronger focus. Each animated wording belongs to the active source chain. All recorded variants and references remain accessible.
- The university theme and logo, Arabic and English interfaces, verified English hadith text and source-linked narrator appraisals.
- A unified evidence-grounded assistant, text-to-tree extraction and interactive practice.

## Run requirements

A valid provider API key is required for generated AI features. Each local installation supplies its own key in `API.env`. No live-demo key is included in the repository or ZIP. Follow the [README](../README.md).

Source-only operation remains explicitly labelled. The assistant's evidence search covers recorded library excerpts. External model availability depends on the provider; a Gemini key does not grant a Sunnah.com API entitlement. See [AI-WORKBENCH.md](AI-WORKBENCH.md) for the exact limits.
